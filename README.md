# 卫戍协议助手

`v1.2.1` · AstrBot 插件

通过森空岛扫码绑定账号，查询《明日方舟》卫戍协议的赛季统计、近期战绩和单局详情。新对局播报默认关闭。

## 安装

在 AstrBot 面板打开 **插件 → 安装插件 → 从文件安装**，选中发布 ZIP。安装后确认「卫戍协议助手」处于启用状态。同名插件可直接覆盖更新，不必先卸载；已有配置不会被新默认值覆盖。

插件声明要求 AstrBot 4.10.0 或以上，Python 依赖见 [requirements.txt](requirements.txt)。随包提供中文字体，不需要额外安装系统字体。

## 绑定与查询

1. 群里用 QQ 的 @ 功能真正艾特机器人，再发 `/卫戍 绑定`，机器人只回复绑定指引。
2. 打开机器人私聊，发送 `/卫戍 绑定`，不用 @。非好友可从共同群聊点击机器人头像，选择「发消息」，然后在临时私聊里发送同一指令。
3. 用自己的森空岛 App 扫码。二维码和绑定结果只回复到发起绑定的私聊，不会发到群里。二维码默认 100 秒有效，不要转发。

QQ 临时私聊需要 QQ 允许建立会话，且 SnowLuma OneBot v11 能接收并回复该会话。临时私聊支持 `/卫戍 帮助`、`/卫戍 绑定`、`/卫戍 解绑`；如果无法打开会话或收不到回复，请改用好友私聊。绑定完成后可以回群查询。

| 命令 | 用途 |
| --- | --- |
| `/卫戍 查询` | 查看本人的赛季统计 |
| `/卫戍 战绩 10` | 查看本人最近 10 场对局 |
| `/卫戍 战绩 10 多人 中断` | 最近 10 场符合条件的战绩；支持 全部/多人/单人/极速/终极 × 全部/完成/中断。用表中原序号查详情 |
| `/卫戍 趋势 炎 终极` | 指定范围最近 10 场，从旧到新；不指定盟约则选该范围最常激活的盟约。缺测留空，不算作零层 |
| `/卫戍 对局 1` | 查看本人最近一局详情 |
| `/卫戍 状态` | 查看绑定和播报状态 |
| `/卫戍 解绑` | 解除绑定，或在私聊取消正在进行的扫码 |
| `/卫戍 推送 开` / `/卫戍 推送 关` | 开启或关闭新对局播报 |

群里发任何卫戍命令都需要真 @，只能查询自己的战绩，结果对群成员可见。要把新对局播报到某个群，请在该群执行推送开启命令。每个账号只选择一个播报会话；临时会话不用于后台播报。

## 配置与数据

- `proxy` 默认留空；如需代理，请使用可信地址。
- `poll_interval_seconds` 默认 300 秒，最低 120 秒；`max_push_per_round` 默认 3 条。
- `push_enabled_default` 默认 `false`；设为 `true` 时，仅对普通私聊绑定自动开启本人私聊播报。
- `qr_timeout_seconds` 默认 100 秒；`admin_ids` 默认留空，仅允许显式列入白名单的管理员在私聊查询他人数据。

插件会保存战绩查询所需的森空岛凭证，而非账号密码。只向可信的机器人扫码授权，不要分享登录二维码或插件的 `bindings.json`。森空岛相关接口可能变化；本插件不是游戏官方客户端。
